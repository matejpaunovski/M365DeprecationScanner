# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work, and help newcomers. Harassment and personal attacks are not tolerated.

The Code of Conduct applies to all project spaces: issues, pull requests, discussions and any other place where you represent the project.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainer privately:

- through a [private GitHub security advisory](https://github.com/matejpaunovski/M365DeprecationScanner/security/advisories/new) (only the maintainers can see it), or
- by contacting the maintainer directly via their GitHub profile.

Reports are handled confidentially. Enforcement follows the [Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) of the Contributor Covenant.
